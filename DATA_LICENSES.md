# Data and Model Terms

The repository's software license applies to repository code only.  It does
not grant rights to the upstream datasets, raw text, model weights, or provider
trademarks.

## MIND

Users must obtain MIND from its official distribution and comply with its
research-use terms.  This repository does not redistribute article text or raw
behavior logs.

## Amazon Reviews 2023

Users must obtain Amazon review/metadata files from the official dataset
distribution and comply with the associated terms.  This repository does not
redistribute raw review or item-description text.

## Yelp Open Dataset

Users must obtain Yelp data from the official Open Dataset distribution and
comply with its license/terms.  This repository does not redistribute raw
business or review text.

## Model providers

Llama and Qwen weights remain governed by their providers' licenses and access
requirements.  Model weights are not included.

## What this repository distributes

The public release contains sanitized ranking indices, local candidate
labels, metrics, UQ scores, stable record keys, configuration, and evaluation
outputs. See the [released data specification](docs/RELEASED_DATA.md) for
the record transformation.
