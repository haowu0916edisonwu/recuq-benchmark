# Camera-ready figures

[reference](reference/) contains the figure assets for the camera-ready
manuscript. The pipeline PNG is a raster preview of Figure 1. Figure 2's left
panel uses the pooled Warm-start Error-AUROC values from Table 3 for both
backbones.

Run `make figures` from the repository root to regenerate the result plots
(Figures 2, 4, and 5) and render the case-study values (Figure 3). The case-study
script renders a programmatic version of the manually typeset manuscript figure.
